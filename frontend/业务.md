
标准ERP财务系统的业务流程是**"从业务单据到财务凭证，再到账簿报表"**的完整链路：
```
业务流程顺序：
1. 费用报销/应收/应付管理 → 2. 凭证生成 →（过账）—> 3. 总账记账 → 4. 财务报表 → 5. 月末结账
```
结合前文ERP财务流程、模拟数据，**逐环节+场景+名词落地讲解**，搭配业务动作、系统操作、会计逻辑，易懂好落地。

## 1. 费用报销模块
**场景**：员工张三外出办事，产生交通费500元、住宿费800元，回公司申请报销。
- **费用报销单**（业务单据）
  张三在ERP系统填写单据，填写事由、费用类型、金额，上传票据，生成单号**BX20240501**，提交部门&财务审核。
  作用：留存业务原始依据，证明费用真实发生。
- **差旅费**
  本次报销的费用类型，企业日常行政人员差旅费，财务统一计入**管理费用**。

审核通过后，单据进入财务环节，等待生成凭证。

## 2. 应收管理模块
分为“应收”和“核销”，应收是客户欠公司的货款，核销是公司收款的货款。后者用于确定到底收了多少钱。
**场景**：公司向客户A销售货物，货已发出、款项暂未收到。
- **应收单**（业务单据）
  销售同事在ERP录入销售明细、客户、欠款金额10000元，生成单号**YS20240501**。
- **应收账款**
  专业释义：客户欠公司的货款（企业资产）。
  场景含义：客户A还没付的10000元，系统自动挂账为应收账款，后续收款时再核销。

## 3. 应付管理模块
**场景**：公司向供应商采购原材料，货物已入库，货款暂时未支付。
- **应付单**（业务单据）
  采购人员在ERP录入采购信息、供应商、欠款金额5000元，生成单号**YF20240501**。
- **应付账款**
  专业释义：公司欠供应商的货款（企业负债）。
  场景含义：这5000元是公司待支付的款项，后续付款后再结清。

> 小结：以上**报销单、应收单、应付单**统称为**业务单据**，是财务做账的源头。

## 4. 凭证生成
**场景**：财务月底统一处理，在ERP中执行「单据转凭证」操作。
- **记账凭证（财务凭证）**
  系统根据前面3张业务单据，按照预设会计模板，**自动生成会计凭证**，凭证号：**PZ-2024-001**。
  对应本笔业务简易分录：
  1. 报销差旅费：借 管理费用 1300  贷 银行存款 1300
  2. 销售挂应收：借 应收账款 10000  贷 主营业务收入 10000
  3. 采购挂应付：借 原材料 5000  贷 应付账款 5000
- 作用：把前端业务语言，转换成财务标准会计语言。

## 5. 总账记账
在凭证生成中点击「过账」按钮，那么就会把记录正式登记在账本上
那么这个时候，科目余额就会发生改变
科目余额 就是每个会计科目在某个时间点的剩余金额
也就是这家公司的财产数据存量

借方 = 增加（大部分科目）
贷方 = 减少（大部分科目）

**场景**：财务审核凭证无误后，做凭证过账。
- **凭证过账**
  在ERP点击「过账」，将记账凭证的数据，正式登记到账本中。
- **总账（总分类账）**
  企业核心汇总账簿，过账后系统自动更新各**会计科目**余额：
  - 管理费用增加1300元
  - 银行存款减少1300元
  - 应收账款增加10000元
  - 原材料增加5000元
  - 应付账款增加5000元
  所有科目变动都会实时体现在总账里，是后续出报表的基础。

## 6. 财务报表
展示公司的整体财务情况

**场景**：账务全部过账完成，财务出具月度报表。
- **资产负债表**
  取自总账科目**期末余额**，反映2024年5月31日当天的财务状况：
  能查到：应收账款10000、应付账款5000、银行存款、原材料等资产、负债数据，看清公司当下“家底”。
- **利润表**
  取自总账科目**本期发生额**，反映2024年5月整月经营情况：
  能查到：本月收入、管理费用1300元等，核算当月是盈利还是亏损。

## 7. 月末结账
这个项目不太需要

**场景**：5月所有单据、凭证、报表核对全部无误，执行月结。
1. **结转本期损益**
   系统自动把本月收入、费用这类**损益类科目**余额，全部转入「本年利润」，计算当月最终利润。结转后，收入、费用科目当月余额清零。
2. **会计期间**
   企业按自然月划分做账周期，当前为**2024年5月**。
3. **月末结账**
   ERP执行结账操作，**关闭2024年5月会计期间**。
   场景限制：结账后，无法再新增、修改、删除5月的单据和凭证，5月账务正式封存，系统进入2024年6月做账周期。
