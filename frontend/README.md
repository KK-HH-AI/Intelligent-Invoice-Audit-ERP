# ERP 财务管理系统 - 使用文档

## 一、项目简介

本项目是一个基于 Vue 3 + Pinia 的前端 ERP 财务管理系统，实现了从业务单据到财务报表的完整财务流程。系统采用纯前端架构，数据存储在浏览器内存中（Pinia 全局状态管理）。

### 技术栈
- **Vue 3** - 前端框架
- **Vue Router** - 路由管理
- **Pinia** - 全局状态管理
- **Vite** - 构建工具

### 系统模块
| 模块 | 功能说明 |
|------|----------|
| 费用报销 | 员工报销申请、审批管理 |
| 应收管理 | 销售应收单创建、收款核销 |
| 应付管理 | 采购应付单创建、付款核销 |
| 凭证生成 | 从业务单据自动生成会计凭证 |
| 总账记账 | 查看科目余额表 |
| 财务报表 | 资产负债表、利润表 |

## 二、快速开始

### 1. 环境要求
- Node.js 14+
- npm 或 yarn

### 2. 安装依赖
```bash
npm install
```

### 3. 启动开发服务器
```bash
npm run dev
```

### 4. 访问系统
浏览器打开终端显示的地址（通常为 `http://localhost:5173`）

## 三、使用流程

系统遵循标准 ERP 财务流程：**业务单据 → 凭证生成 → 过账 → 总账 → 报表**

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  业务单据   │───>│  凭证生成   │───>│  总账记账   │───>│  财务报表   │
│             │    │             │    │             │    │             │
│ ·费用报销   │    │ ·选择单据   │    │ ·科目余额   │    │ ·资产负债表 │
│ ·应收单     │    │ ·生成凭证   │    │ ·借贷方发生 │    │ ·利润表     │
│ ·应付单     │    │ ·审核/过账  │    │             │    │             │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

## 四、详细操作指南

### 第一步：创建业务单据

业务单据是财务做账的源头，包括费用报销单、应收单、应付单三种类型。

#### 1. 费用报销

**场景**：员工出差产生费用，申请报销。

**操作步骤**：
1. 进入「费用报销」页面
2. 点击右下角 **+** 按钮，打开新增报销单对话框
3. 填写报销信息：
   - **报销人**：员工姓名
   - **报销类型**：差旅费/交通费/住宿费/办公费/招待费
   - **报销金额**：费用金额
   - **报销说明**：费用事由
4. 点击「提交」，生成报销单号（如 `BX20240501`）
5. 在「待审批」Tab 中点击「审核通过」，单据状态变为已通过

**状态说明**：
- `待审核`：刚提交的单据，等待审批
- `已通过`：审批通过，可生成凭证
- `已驳回`：审批不通过

#### 2. 应收管理

**场景**：公司向客户销售货物，款项暂未收到。

**操作步骤**：

**创建应收单**：
1. 进入「应收管理」页面
2. 点击「+ 新增应收单」
3. 填写信息：
   - **客户名称**：客户公司名
   - **应收金额**：销售金额
   - **业务类型**：销售商品/提供服务/其他
   - **说明**：业务描述
4. 点击「提交」，生成应收单号（如 `YS20240501`）

**收款核销**：
1. 点击「收款核销」按钮
2. 选择要收款的应收单
3. 填写收款金额（不能超过未收金额）
4. 选择收款方式：银行转账/现金/支票
5. 点击「确认核销」

**状态说明**：
- `未收款`：全额未收
- `部分收款`：已收部分款项
- `已结清`：全部款项已收

#### 3. 应付管理

**场景**：公司向供应商采购，货款暂未支付。

**操作步骤**：

**创建应付单**：
1. 进入「应付管理」页面
2. 点击「+ 新增应付单」
3. 填写信息：
   - **供应商名称**：供应商公司名
   - **应付金额**：采购金额
   - **业务类型**：采购原材料/采购服务/其他
   - **说明**：业务描述
4. 点击「提交」，生成应付单号（如 `YF20240501`）

**付款核销**：
1. 点击「付款核销」按钮
2. 选择要付款的应付单
3. 填写付款金额（不能超过未付金额）
4. 选择付款方式
5. 点击「确认付款」

**状态说明**：
- `未付款`：全额未付
- `部分付款`：已付部分款项
- `已结清`：全部款项已付

---

### 第二步：生成凭证

凭证是将业务单据转换为会计语言的关键环节。

**操作步骤**：
1. 进入「凭证生成」页面
2. 点击「+ 从业务单据生成凭证」
3. 选择单据类型：
   - **费用报销单**：仅显示已审核通过的单据
   - **应收单**：显示所有应收单（无论是否结清）
   - **应付单**：显示所有应付单（无论是否结清）
4. 选择具体单据
5. 选择凭证日期
6. 点击「生成凭证」

**凭证自动生成规则**：

| 单据类型 | 借方科目 | 贷方科目 |
|----------|----------|----------|
| 费用报销 | 管理费用（6602） | 银行存款（1002） |
| 应收单 | 应收账款（1122） | 主营业务收入（6001） |
| 应付单 | 主营业务成本（6401） | 应付账款（2202） |

**凭证状态**：
- `草稿`：刚生成的凭证，待审核
- `已审核`：审核通过，待过账
- `已过账`：已登记到总账

---

### 第三步：审核与过账

**审核凭证**：
1. 在凭证列表中找到状态为「草稿」的凭证
2. 点击「审核」按钮
3. 凭证状态变为「已审核」

**过账**：
1. 在凭证列表中找到状态为「已审核」的凭证
2. 点击「过账」按钮
3. 凭证状态变为「已过账」
4. 系统自动将凭证分录登记到总账科目中，更新科目余额

> **注意**：只有过账后的凭证才会影响总账和报表数据！

---

### 第四步：查看总账

**操作步骤**：
1. 进入「总账记账」页面
2. 查看科目余额表，包含：
   - **科目编码**：会计科目代码
   - **科目名称**：会计科目名称
   - **期初余额**：期间开始时的余额
   - **本期借方**：本期借方发生额合计
   - **本期贷方**：本期贷方发生额合计
   - **期末余额**：期末余额 = 期初 + 借方 - 贷方

**初始科目余额**：

| 科目编码 | 科目名称 | 期初余额 |
|----------|----------|----------|
| 1002 | 银行存款 | ¥100,000.00 |
| 1122 | 应收账款 | ¥0.00 |
| 2202 | 应付账款 | ¥0.00 |
| 6001 | 主营业务收入 | ¥0.00 |
| 6401 | 主营业务成本 | ¥0.00 |
| 6602 | 管理费用 | ¥0.00 |

---

### 第五步：查看财务报表

**操作步骤**：
1. 进入「财务报表」页面
2. 选择报表类型

#### 资产负债表
反映企业在特定日期的财务状况（资产 = 负债 + 所有者权益）。

| 项目 | 数据来源 |
|------|----------|
| 银行存款 | 科目 1002 期末余额 |
| 应收账款 | 科目 1122 期末余额 |
| 应付账款 | 科目 2202 期末余额 |
| 所有者权益 | 资产合计 - 负债合计 |

#### 利润表
反映企业在一定期间的经营成果。

| 项目 | 数据来源 |
|------|----------|
| 主营业务收入 | 科目 6001 期末余额（取绝对值） |
| 主营业务成本 | 科目 6401 期末余额 |
| 管理费用 | 科目 6602 期末余额 |
| 净利润 | 收入 - 成本 - 费用 |

> **注意**：利润表不显示合计行，"净利润"即为最终结果。

## 五、完整业务场景示例

### 场景：一笔销售业务的完整流程

**背景**：公司向客户A销售产品，金额 ¥10,000。

| 步骤 | 操作 | 结果 |
|------|------|------|
| 1 | 应收管理 → 新增应收单 | 生成应收单 YS20240501 |
| 2 | 凭证生成 → 选择应收单 → 生成凭证 | 生成凭证 PZ-2024-001（草稿） |
| 3 | 凭证列表 → 点击「审核」 | 凭证状态变为已审核 |
| 4 | 凭证列表 → 点击「过账」 | 凭证状态变为已过账，总账更新 |
| 5 | 总账记账 | 应收账款 +¥10,000，主营业务收入 +¥10,000 |
| 6 | 财务报表 → 资产负债表 | 应收账款显示 ¥10,000 |
| 7 | 财务报表 → 利润表 | 主营业务收入显示 ¥10,000 |

## 六、会计基础知识

### 借贷记账规则

| 科目类型 | 借方表示 | 贷方表示 |
|----------|----------|----------|
| 资产类 | 增加 | 减少 |
| 负债类 | 减少 | 增加 |
| 收入类 | 减少 | 增加 |
| 成本费用类 | 增加 | 减少 |

### 科目余额计算

```
期末余额 = 期初余额 + 借方发生额 - 贷方发生额
```

### 会计等式

```
资产 = 负债 + 所有者权益
```

## 七、注意事项

1. **数据持久化**：当前系统数据存储在浏览器内存中，刷新页面后数据会丢失。如需保留数据，请勿刷新页面。

2. **操作顺序**：必须按照「创建单据 → 生成凭证 → 审核 → 过账」的顺序操作，跳过步骤会导致数据不完整。

3. **凭证过账**：只有过账后的凭证才会影响总账和报表数据，草稿和已审核状态的凭证不会影响报表。

4. **核销金额**：收款/付款核销时，金额不能超过未收/未付金额。

5. **利润表显示**：收入类科目在总账中为负数（贷方增加），报表中已自动取绝对值显示为正数。
